# Track 4 可行性结论（2026-10-06，scorer 5.2.2 / toolkit 2.6.0）

## 结论：值得做，作为副赛道。风险可控，上限有限。

不用大模型也能交一份**稳定可接纳、零虚假引用、明显好于官方基线**的答卷；但要在密封题上大幅超过
"把上期值原样带过去"的 naive 规则，靠确定性方法只能做到小幅领先。House 模型在我们这台机器上连不上，
所以 LLM 层只做成可选增强，默认关闭。

## 现在到底怎么算分（以 scorer 源码为准）

| 部分 | 公式 | 要点 |
|---|---|---|
| 预测质量 pq（权重 0.7） | 分类=准确率，排序=(ρ+1)/2，二者都**锚定 naive 规则**（naive 得 0.5，满分 1）；回归 = naive_MAE/(naive_MAE+MAE) | naive 规则在 `reference/naive_answer.json`，**不公开**；文档只说"通常是把上期值带过去" |
| 区间质量 iq（权重 0.3） | naive_IS/(naive_IS+IS)，IS = 宽度 + 20×落在区间外的距离 | **封顶 max(0.5, pq)**：预测不比 naive 好，区间再准也最多 0.5；宽度现在要扣分 |
| 忠实度 | 总分 × (1 − F/(F+min(T,3E)))，F=虚假 claim 数 | 不再是门槛，是按条扣分；**逐字引用原文的 claim 不送 NLI、必然不算假** |
| 推理分（只在决赛后离线评） | final = −0.27 + 1.27×analysis + 0.25×reasoning | LLM 评审拿 `submitted_reasons` 对比隐藏的"标准理由"；不交不扣分 |
| 直接判死（W=0，榜上 −0.27） | schema 错、实体缺/多/重、NaN、引用了截止日之后或不存在的文档、崩溃/超时 | 要绝对避免 |

Development 榜不跑 NLI 矛盾检查；确定性规则（实体归属、越界、数字核对、空洞句、8000 字上限）两个阶段都跑。

## "表格 ML" 能不能做

不能照字面做：每个 unit 只有 1–12 行，**没有标签**，跨 unit 也没有可训练的结果。能做的"ML"是：
用语料表格里**截止日前的历史序列**在 unit 内做回测选参（多实体合并拟合），这就是我们实现的方式。

## 我们的做法（全部确定性，零网络）

1. **嵌入式截止日过滤**：读文本之前就丢掉 doc_date > cutoff 的文档（防 stale 陷阱）。
2. **预测**（按证据强弱依次尝试，任何一步出错退回下一步）：
   - 申报文件里最近一季 diluted EPS 同比变化 → 一半带入目标季度（EPS 类）；
   - 修订表（vintage）→ 同"修订轮次"的历史平均修订（宏观修订类）；
   - 持续经营疑虑 / 净亏损 / 违约用语密度 → 信用事件概率；
   - 语料 `a | b | c` 表格里的历史序列 → 末值与均值混合（权重、窗口由全体实体合并回测选），或均值回归（变化量目标）；
   - 都没有 → 带上期值（或 0 变化），区间按量纲和时间窗给。
   - 三分类（beat/inline/miss 一类）用正态预测分布取概率最大的标签，而不是默认中间档。
3. **引用**：每条 claim 都是 manifest 标给该实体（或 shared）的文档的**逐字切片**，或该实体自己的 task 行；
   官方 `check_claim_rules` 在 11 个公开 unit 上 0 条虚假。
4. **理由**：最多 3 条 `submitted_reasons`，premise 为逐字原文，mechanism 写清楚算法和数字。
5. **永不崩溃**：主流程任何异常都写出由 task.json 生成的最小合法答案并 exit 0；POSIX 下 420 秒硬闹钟（600 秒还包括拉镜像和建容器）。

## 本地成绩（8 个能本地还原结果的公开 unit）

真实结果是我们**凭记忆**写的近似值，naive 规则是**猜的**；只用于"我们 vs 官方基线"的相对比较。

| 指标 | 我们 | 官方 baseline_agent |
|---|---|---|
| 平均 analysis 分 | **0.68**（榜面 ≈ 0.60） | 0.46（榜面 ≈ 0.31） |
| 虚假 claim（11 个 unit 合计） | **0** | 17 |
| 可接纳 unit | 11/11 | 11/11 |

逐个 unit 见 `STATUS.md`。利率（FOMC）两个 unit 我们与 naive 打平（0.50）：零变化就是无信息时的最优点预测。

## 对密封题的现实预期

公开题里有 4 类我们写了专门信号（EPS、修订、信用、表格序列）；密封题"大多数家族没有公开对应"。
没有信号的家族会退回"带上期值"，约等于 naive（0.5 左右）。合理预期 analysis ≈ 0.50–0.60，
官方基线大约 0.30–0.45。最大的不确定是 naive 规则本身：如果它比"带上期值"更聪明，我们的领先会缩小。

## 主要风险与对策

- 失败一次即淘汰：镜像内置自测 + CI 在平台同等限制下跑全部公开 unit + 17 个异常输入用例。
- naive 规则未知：所有偏离锚点的模型都做了收缩，且只用截止日前数据拟合。
- House 模型不可测：默认关闭；打开时最多 3 次调用、单次 90 秒、严格 JSON、只能在确定性区间内挪一半。
