## 结论（先看这个）

1. **v4_eval 的度量是忠实的。** 我的独立实现与 v4_eval 在 90 张卡上逐卡差异 = 0（max|diff| 0.0），
   v4 = **0.9220**、v3 = **1.1389**，与 V4_NOTES 完全一致。M0 原始三分量（marginal/tail）逐卡比值 1.000000。
   M0 自检：用我的 M0 抽样喂给官方 scorer，90/90 张卡得 1.0000（误差 1e-14）；月度卡步数 8/9、2 与文档表一致。
2. **v4 相对 M0 的优势在样本内统计显著**（按 as-of 分组 cluster bootstrap，78 组）：
   v4 − M0 = **−0.078，95% CI [−0.112, −0.044]**；对“自己种子 + 2000 抽样的 M0 克隆”是 −0.061 ~ −0.079。
   但这是**选参后的样本内**数字；种子平均后 v4 ≈ 0.929（种子 20260909/1/2 = 0.922/0.933/0.929），
   默认种子在 F1 上是 7 个种子里最幸运的一个。
3. **两个常数是对“公开卡 = 事后挑选的样本”下注，存在不对称尾部风险**：
   F1 宽度 ×0.9 和 F4 宽度 ×1.25。建议 **F1 → 1.0，F4 宽度 → 1.0（保留 mixture p0.2/k1.5 + 应力方向位移 1.0）**，
   F3 drift 0.5 保留。样本内代价约 +0.016（种子平均 0.929 → 约 0.945），换来下面压力测试里避免的 +0.1~+0.35/卡 的损失。
   **不建议回退到 M0 克隆**（M0-like = 0.993，F3/F4 的改进是稳的）。

## 发现（按严重度）

### S1（高）F1 ×0.9 处在悬崖边上
- 种子平均（6 个种子，18 张可评分 F1 卡）：宽度 0.8 / 0.9 / 0.95 / 1.0 → **1.159 / 0.937 / 0.921 / 0.962**。
  从 0.9 再收 10% 就比 M0 差 16%——损失高度不对称（单资产两期限卡的 variogram 只有一项平方差，宽度偏窄时比值爆炸）。
- 公开 F1 卡的实现值异常平静：相对 M0 的 z² 中位数 **0.18**（名义应为 1）。0.9 的收益来自这种“事后看很平静”的样本。
  且 F1 增益的 1/3 来自单张卡 `t2-F1-jpy-ycc-flex-2018`（−0.58）；去掉它 F1 平均增益从 −0.089 降到 −0.06。
- 压力测试（把实现值离 M0 中心的偏离放大 k 倍，M0 分母同步重算，3 种子平均）：

  | k | w0.9 | w0.95 | w1.0 |
  |---|---|---|---|
  | 0.5 | 0.879 | 0.926 | 0.982 |
  | 1.0（公开实况） | 0.943 | 0.923 | 0.958 |
  | 1.25 | **1.057** | 1.008 | 1.004 |
  | 1.5 | **1.294** | 1.149 | 1.047 |

  封存 F1（2025H2–2026H1）只要比公开 F1 波动大 25%（仍然比名义平静），0.9 就输给 M0；1.0 基本不输。
  对全局均值，0.9 相对 1.0 的样本内好处只有 ≈ 0.025 × 18/90 = **0.005**。→ **改为 1.0**（0.95 是可接受的折中）。

### S2（高）F4 ×1.25 + 位移依赖“封存 F4 卡也有大冲击”
- 公开 F4 实现值相对 M0 的 |z| 中位数 **2.8**，29 张里 23 张 max|z| ≥ 1.5：作者是事后挑的冲击事件。
  在这 23 张上 v4 比 M0-like 好 −0.193/卡；在 6 张平静卡上差 **+0.142/卡**（qe1-expansion-2009 +0.33、ust10y-supply-2023 +0.23）。盈亏平衡冲击占比 ≈ 42%。
- 压力测试（4 种子平均，k = 实现偏离缩放）：

  | k | adopted (w1.25+mix+shift) | w1.0+mix+shift | M0-like |
  |---|---|---|---|
  | 0（完全无冲击） | **1.462** | 1.164 | 0.996 |
  | 0.3（≈普通日子） | **1.123** | 0.995 | 0.993 |
  | 0.6 | 0.932 | 0.914 | 0.992 |
  | 1.0（公开实况） | 0.861 | 0.894 | 0.994 |
  | 1.5 | 0.836 | 0.893 | 1.006 |

  拆分（种子平均）：w1.25 无 mixture 0.937；mixture 无位移 0.919；w1.0+mixture+位移 0.892；adopted 0.859。
  位移（方向表）是主要贡献，宽度 1.25 只再多 0.033。→ **宽度改 1.0，保留 mixture + 位移**：普通日子不亏，冲击日仍拿大部分收益。
  若确信封存 F4 必含冲击（README：“harness knows which cards are tail/shock cards”）可保留 1.25，但这是押注而非校准。

### S3（中）样本内数字偏乐观；“forward” 才是更现实的估计
- 选参在同一 90 张卡、同一引擎种子上做；默认种子 F1 = 0.9065 是 7 个种子中最好（其他 0.928–0.961）。
- 噪声底：M0 克隆（同分布不同种子）总分 0.983–1.001，**F1 家族均值仅因种子就在 0.94–1.02 之间摆动**。
  F2 家族 v4（= M0-like 行）是 1.009，即比 M0 略差，属噪声。
- V4_NOTES 的 forward（≤2018 选 → ≥2019 测）= 0.991 ≈ M0，留一时代 0.929；真实期望大概在两者之间。
  我没有重跑 320 组 sweep/CV，只独立复核了被采纳的行及其邻域（上表）。

### S4（中）评估器与官方 scorer 共有的未验证假设（影响 v3/v4 两边，非 v4_eval 的 bug）
- **实现值是用兄弟卡面板重建的**：我独立复核了 200 个 level 格（池化面板取 target_date 当日值，200/200 一致）
  和 29 个 log_return 格（Σlog1p(r)，29/29 一致）。但 target_date 采用 as-of + h 个 BDay（无假日日历）这一约定两边共用，未能验证。
- **M0 格子顺序**：文档说 103 张中 3 张用 `[targets]` 原序而非排序，哪三张未知；那几张 M0 抽样不同，单分量可差 ±30%（噪声，非偏差）。
- 4 张月度宏观卡无实现值，不在 90 张里；v4 在月度卡上走 observation_periods 步数，与 M0 一致（已核对 8/9、2）。

### S5（低）信息泄露 / 稳健性检查：未发现问题
- engine/ 中无 realized、pkl、unit id 或具体日期查表；`assets.py` 只按资产 id 给应力方向（合法）。镜像只 COPY `engine/`，`.v4_cache.pkl` 不进镜像。

  `--text /input/text` 的父目录即卡片目录，可读到。实测把卡改成未知家族（id `t2-sealed-0042`、category `T2-Fx`）→ 走 default 行（M0-like），正常输出。

## 文档歧义与处理（scorer 源码优先）

1. “每个分量除以 M0 后截断”——源码是先算加权合成 `w·(c/ref)`，再对**单卡合成分**做 `plan.clip` 到 [0,4]，不是逐分量截断。v4_eval 也是这样做的。
2. 聚合：`Aggregate.from_results` 对全部名册卡 `fsum/len`（算术平均），失败卡计 4.0。
3. 分量 ≤ 0 时 scale 存 1.0（M0 §5）；单格卡 joint 权重为 0，scale 的 joint 可缺省，结果不变。
4. 尾部默认 pinball（`tail.py`），水平取均值；卡片均未声明 `tail_metric`。
5. §3.7 目标日期封存：月度卡用 observation_periods，其余用 as-of + h BDay；日频面板 2× 规则下都回到声明 horizon。
6. §3.6 “面板最后一个观测”取 ≤ as-of 的最后一行（公开面板本就截在 as-of）。
7. 官方 `load_ref_scale` 用了 POSIX 专有的 `os.O_DIRECTORY`，Windows 上无法运行；审计脚本直接构造 loader 会构造的 `RefScale` 对象传入，其余全部走官方代码。
